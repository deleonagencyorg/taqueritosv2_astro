Development¶

Using the provided build tools, you can quickly setup the development environment and start customizing the game very easily.

Setup environment¶

  • Install nodejs

  • Run Window command line program (or Terminal app in Linux/Unix OS)

  • Change current directory to the game folder

  • Type “npm install -y”

  • Once finished, type “npx vite” to launch a local http server in the background and start developing

  • Test the gallery by go to “http://localhost:3737/”

Entry point¶

To bootstrap the game, the code in “src/entry.ts” will query the root container element then construct and launch the game.
