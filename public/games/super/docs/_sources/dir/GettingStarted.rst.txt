
Getting Started
===============

What's inside
-------------

* **dist**
    Game production-ready files, you can upload the content of this directory to your web server to deploy the game.
* **public**
    Game public assets including graphics, sounds, 3d models, CSS files...
* **src**
    Main Typescript source files.
* **vite.config.ts**
    Vite build file in typescript
* **tsconfig,json**
    Typescript config file
* **package.json**
    node.js project file.
* **docs**
    Documentation includes html and pdf format

Use production ready files
--------------------------

  The *dist* folder contains everything you need to deploy the game to different mediums. The files are compressed and optimized to
  be embedded in website or integrated in a Cordova app.
